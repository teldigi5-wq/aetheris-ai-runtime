# Threat Modeling for Aetheris
Map protected assets, allowed actors, entry points, data flows, external dependencies and trust boundaries. List threats by spoofing, tampering, repudiation, information disclosure, denial of service and privilege escalation; add agent-specific prompt injection, malicious skill supply-chain, forged approvals, tool-output laundering and evidence poisoning.

Propose prevention, detection, recovery and a verifiable test for every high-risk threat. Enforce separation of *advice*, *approval*, *action* and *post-action attestation*. No skill or LLM output may assign owner status, widen Docker network scope, access host secrets or bypass Stage45. Owner identity and production release remain out of scope until separate certification.
