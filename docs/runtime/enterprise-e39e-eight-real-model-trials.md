# Aetheris E3.9C-2B2 — genuine Hermes3B versus Granite4 3B on eight keyboard faults

**Draft research experiment, eight synthetic published source faults per model.** This is not blinded outside the source repository, not statistically representative, and not authorization to work on owner PC, production or protected main. **Actual model quality numbers are unknown until exact-head CI and inspected transcripts are complete.**

## Exact independent experimental contract

- Both published model tags, `hermes3:3b` (Nous Research, approx. 2.0 GB) and `granite4:3b` (IBM, approx. 2.1 GB), run as **genuine Ollama inference**, one model per independent disposable Ubuntu runner. We use pinned Ollama container image from verified prior E3.9C-2A, with **2 CPU, 5 GiB memory cap, 128 PIDs, read-only root, all capabilities dropped and loopback-only exposed endpoint**. Only CI pulls model weights into an ephemeral Docker volume. Never owner's workstation.
- Eight source faults are the genuine Chromium-tested cases from verified E3.9C-2B1 PR #148: `top-40`, `top-120`, `left-120`, `left-240`, `opacity-zero`, `visibility-hidden`, `transform-up`, `transform-left`.
- The local-model adviser `e39e_real_model_adviser.py` requires **`AETHERIS_E39E_REAL_MODEL_CI_OPT_IN=yes`** and fixed model/case identities. It sees only a small CSS excerpt containing the faulty `.skip-link:focus` rule and actual Chromium measurements at mobile 390px and desktop 1280px. It imports **no evaluator, expected source patch or policy module**. Source/browser text is untrusted; prompts cannot authorize tools or actions. Only one bounded JSON reply per case, no retry, temperature 0. It can abstain.
- Structured model reply grammar: `{"operation":"abstain"}` OR `{"operation":"replace","selector":".skip-link:focus","property":"top|left|opacity|visibility|transform","value":"..."}`. The actual JSON property contains ONE of those five names, not the pipe-separated illustration. Arbitrary code, files, functions, URL, commands, extra JSON keys and model-issued owner approvals are rejected. Duplicate JSON keys, wrong type, stale case/source and extra owner claims are refused by the **separate** independent parser.
- `e39e_model_policy.py` runs any accepted proposal through the **fixed `e39e-apply` phase of the preexisting network-none Docker worker**. It verifies the source is exactly one original synthetically defective focused rule and ALL other CSS is byte-for-byte canonical with generated-manifest SHA256; both before-Chromium proofs must match. For each defect it enforces only one property+value grammar: top/left `0–24px`, opacity `1` or `0.95`, visibility `visible`, transform `none`. Values for different properties are not interchangeable. This contract is reviewed, not a general-purpose CSS parser. It performs no privileged action or GitHub write.
- If policy ACCEPTS, independent real Chromium Tab-focus browser checks run at both viewport widths. The model receives credit only if BOTH actual browser tests pass. If policy REFUSES, the source must remain unchanged; model may abstain or return invalid text and earns 0. Browser-after failure after policy acceptance also earns 0.
- After the independent score is written, the **fixed network-none `e39e-cleanup CASE` test-only command** restores the generated original site solely so the next seeded synthetic defect can start clean. That reset is explicitly marked `modelGeneratedRepair=false` and is NEVER an AI result or benchmark success. Every case has before/after screenshot/DOM/response/source SHA256 and score receipts.
- Genuine CPU Ollama token counts and wall times, self-reported model digest/size, model response hash and prompt version, isolated Docker boundaries and one-shot snapshots (not measured peak RAM) are retained. Per-model aggregates record attempted 8, policy allowed, verified browser repairs, abstained, malformed JSON, refused, accepted-but-browser-failed. Do not rewrite zero scores or conceal refusals.
- Windows and Ubuntu adversarial negative tests, full Java orchestrator regression, no-owner/Stage45 check and separate untouched original website Chromium regression gate exact-head merge readiness. All PRs remain draft and protected main is unchanged.
