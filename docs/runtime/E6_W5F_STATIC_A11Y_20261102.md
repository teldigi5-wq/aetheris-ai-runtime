## Evidence interpretation

Passing the axe rule subset and keyboard checks is **automated regression evidence, not an independent WCAG 2.2 AA certification**. Automated analysis does not fully detect keyboard traps outside scripted workflows, meaning/semantic quality, actual screen reader output, gesture and user-device OS preferences, real browser 200% zoom or visual design merit. Manual evaluation must remain an explicit approval gate.

A reported scan failure is a genuine blocker for this W5-F CI unless traceable to an inaccurate fixture/instrumentation error; do not weaken axe severity thresholds or suppress reported violations to force green. If issues are in generated markup or base CSS, fix the **actual compiler** and cover with negative tests.
