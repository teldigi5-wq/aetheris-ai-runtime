## Local usage (owner-controlled, not CI)

These commands are optional on the owner's own computer **after reviewing the code and synthetic briefs**. No credential, production site, paid API, cloud service, source code, download or developer hardware access is needed to inspect the default plan.

1. `python3 tools/enterprise/e3_factory/e5_local_brief_evaluation.py --model qwen2.5-coder:1.5b` prints **PLAN_ONLY_NO_LOCAL_MODEL_CONTACT** with **0 model requests and no suite access**.
2. Before a real trial, create the **local-only** file `target/e5/local-evaluation-suite.json` with exactly two to four independently authored, **non-sensitive synthetic research briefs**:

```json
{
  "version": 1,
  "cases": [
    {
      "caseId": "case-one",
      "brief": {
        "version": 1, "brandLabel": "Prototype Atelier",
        "requiredTerms": ["quiet", "motion"],
        "forbiddenTerms": ["certified"]
      }
    },
    {
      "caseId": "case-two",
      "brief": {
        "version": 1, "brandLabel": "Stone Workshop",
        "requiredTerms": ["stone", "craft"],
        "forbiddenTerms": ["guaranteed"]
      }
    }
  ]
}
```

3. Use only an already installed and exact allowlisted local Ollama model. A real run requires ALL THREE opt-ins: `AETHERIS_E36_LOCAL_INFERENCE_OPT_IN=yes`, `AETHERIS_E4_EXPLICIT_LOCAL_SESSION_OPT_IN=yes`, and `AETHERIS_E5_MULTI_BRIEF_EVAL_OPT_IN=yes`; heavyweight candidates additionally require `AETHERIS_E38_HIGH_RESOURCE_MODEL_OPT_IN=yes`. Then run `python3 tools/enterprise/e3_factory/e5_local_brief_evaluation.py --model qwen2.5-coder:1.5b --run-local`. **No automatic pull, installation or cloud fallback.** Opt-in variables are process-level permissions, **not authenticated owner approvals**.
4. Every submitted brief gets a new one-shot `LocalCopyTrial` with at most two host-locked localhost Ollama requests (installed model tag probe + single inference). A suite has **max 4** cases/adapter invocations, with no retry after failure. One model in the allowlist may not be installed; no inference attempt is guaranteed. The complete suite is validated **before the first model request** to avoid wasting calls on malformed cases.
5. A completed run writes at most one local `target/e5/local-evaluation-evidence.zip` file with permissions 0600, and **refuses to overwrite any pre-existing evidence or symlink**. The ZIP has `evaluation.json`, plus one research-only website preview ZIP, source receipt and prior E5 hash evidence for **each accepted** brief; rejected/unavailable cases have no preview and still count in the denominator. Every accepted preview uses the **HUMAN-WRITTEN** E3.9H HTML/JS/CSS reference with escaped copy substituted. No original website code is generated by this script. Treat the local ZIP as potentially sensitive; review and retain it privately, and do not commit or publish it.
6. Once a run has finished, `acceptanceFraction` reports the **lexical schema/term-match ratio** only, not creativity, factual honesty, UI design, conversion, authorship, model authenticity, a11y or production readiness. Repeated held-out model trials, independently reviewed design evidence and real Chromium QA on the owner's resultant accepted ZIPs are still required. The short term list can be satisfied without any creative competence.
7. The script refuses runs if even one opt-in is absent; it validates exact model ID locally; failures never echo raw model content, local paths or private prompts; nonaccepted cases never receive preview artifacts. `local-evaluation-evidence.zip` must be manually archived or deleted **outside this tool** before another run; no automatic deletion or overwrite is allowed.
